Скопируйте тезисы в PowerPoint / Keynote. На каждый слайд — 1 заголовок и 3–5 коротких пунктов. Вставьте блок-схему и 1–2 рисунка из `docs/figures/`.

### Слайд 1. Титул
- Проектирование системы идентификации личности по голосу
- Бригада: … | Группа: … | Преподаватель: …

### Слайд 2. Проблема и цель
- Биометрия по голосу: «кто говорит?»
- Не путать с распознаванием речи (ASR)
- Цель: учебный прототип enroll → identify

### Слайд 3. Связь с курсом «Мультимедийные системы»
- Лек. 3 — оцифровка, fs, АЦП
- Лек. 4 — тембр = основной тон + обертоны
- Лек. 13 — WAV, спектральный анализ (FFT)
- Лек. 17 — этапы проектирования

### Слайд 4. Обзор подходов
- Слепок / GMM / i-vector / x-vector
- Почему выбран MFCC + mean + cosine (объяснимость, срок 1 семестр)

### Слайд 5. Архитектура (блок-схема)
- WAV → VAD → MFCC → слепок `.npy`
- Cosine + порог → имя / «не распознан»

### Слайд 6. MFCC «на пальцах»
- Кадры 25 мс, FFT, mel-фильтры, log, DCT
- Слепок = средний вектор MFCC (тембровая окраска)

### Слайд 7. Реализация
- Python, numpy/scipy (без тяжёлых ML-библиотек)
- CLI + GUI (tkinter)
- Параметры: 16 kHz, 13 MFCC, порог 0.92

### Слайд 8. Демо
- Живой запуск: enroll / identify своего файла
- Или короткий скринкаст

### Слайд 9. Эксперименты

- Влияние порога

### Слайд 10. Ограничения
- Шум, микрофон, малая база
- Нет anti-spoofing
