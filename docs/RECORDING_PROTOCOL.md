# Протокол записи голосов бригады

Замените синтетический демо-набор реальными записями **в тех же папках и именах**.

## Оборудование и условия
- Микрофон ноутбука или гарнитура (один и тот же тип для всех enroll одного человека).
- Тихая комната, без музыки и ТВ.
- Расстояние до микрофона ~20–40 см, ровный уровень громкости.
- Формат: **WAV, 16 kHz, mono, 16 bit** (система сама ресемплирует, но лучше сразу так).

## Структура файлов
```
data/raw/speaker_01/enroll_01.wav … enroll_06.wav
data/raw/speaker_01/test_01.wav … test_04.wav
data/raw/speaker_02/...
data/raw/speaker_03/...
data/raw/impostor/test_01.wav …   # голос человека НЕ из базы (друг/другая запись)
```

В `src/config.py` можно прописать ФИО в `SPEAKER_NAMES`.

## Что говорить
- Режим **text-independent**: разные фразы на русском, 3–5 секунд.
- Примеры: «Сегодня ясная погода», «Номер лабораторной работы пять», чтение 1–2 предложений из учебника.
- Не использовать одну и ту же заученную «пароль-фразу» на enroll и test (иначе система учит текст, а не тембр).

## Рекомендуемый объём
| Тип | На человека |
|-----|-------------|
| enroll | 5–7 фраз |
| test | 3–5 фраз |
| impostor | 3–4 фразы суммарно |

Дополнительно (по желанию): 2 файла в шуме / из другой комнаты — для раздела ограничений в записке.

## После записи
```bash
python -m src.enroll --all
python -m src.metrics --sweep --out docs/metrics_table.csv
```
