# Сценарий защиты (репетиция, ~7–10 минут)

| Минуты | Кто | Что говорит |

## Ключевые фразы «на зубок»

1. **Что в слепке?** Усреднённый вектор из 13 MFCC по речевым кадрам — компактное описание тембровой окраски.  
2. **Зачем FFT?** Чтобы перейти из времени в частоту и увидеть спектр (как Spectrum Analysis в редакторах из лекции 13).  
3. **Зачем mel?** Шкала ближе к восприятию человеком; банк фильтров сжимает спектр.  
4. **Почему не нейросеть?** Нужна объяснимость и объём на один семестр.  
5. **Что если score < порога?** Система отвечает «не распознан» — снижаем FAR.

## Типовые вопросы преподавателя

| Вопрос | Короткий ответ |
|--------|----------------|
| Чем identification отличается от verification? | 1:N поиск в базе vs 1:1 проверка заявленного имени |
| Почему 16 кГц? | Для речи достаточно; теорема Котельникова / лек. 3 |
| Что будет в шуме? | VAD и признаки портятся → растёт FRR; нужны фильтрация/больше данных |
| Можно ли обмануть записью с колонки? | Да, anti-spoofing не делали — ограничение |
| Как улучшить? | GMM на MFCC, больше спикеров, аугментация, x-vector |
